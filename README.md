# AI 영수증 처리 자동화

## 배경

월말마다 AI 계정의 영수증을 출력하고, 회계팀에서 보내준 법인카드 승인내역과 대조하여 영수증을 매칭한다.
매칭된 영수증에는 승인 카드번호 뒷자리, 사용자, 승인금액을 기입하고, 전체 영수증을 60% 크기로 출력한다.
이후 연간 기안에 포함되지 않은 건에 대해 새롭게 기안서를 작성한다.

관리해야 하는 AI 프로그램이 늘어나고, 법인카드가 3개(6571 · 8043 · 1537)로 늘어나면서 처리 시간이 늘어남.
전체적으로 어려운 일은 아니나 손이 많이 가고 시간이 많이 들어갔던 일을 Claude Code를 이용해 자동화.

---

## 프로그램 동작 순서

### 1. 영수증 & 승인내역 매칭
- 영수증 파일(PDF, HTML, PNG/JPG 이미지 스크린샷)과 회계팀 승인내역 PDF를 입력
- 승인내역을 기준으로, 대응하는 영수증이 없는 건을 먼저 알림
- 매칭 기준: 가맹점 + 금액 + 승인날짜(7일 이내 허용) + 카드번호

### 2. 영수증에 승인 정보 표기 후 60% 출력
- 매칭된 영수증에 아래 항목을 자동 표기
  - 카드 뒷자리
  - 사용자
  - 승인금액 (해외 결제만 표기, 국내 원화 결제는 생략)
- 전체 영수증을 60% 크기로 축소한 PDF 1개로 합본 출력

### 3. 기안서 자동 작성
- 연간 기안에 이미 포함된 계정/부서는 기안서 생성 제외
- AX프로젝트는 별도 기안이 미리 있어 영수증 표기만 하고 기안서는 생성하지 않음
- 그 외 신규 결제 건에 대해 기안서(.hwpx) 자동 생성
- 30만원 미만이면 동일 공급업체끼리 묶음 기안서로 처리

### 4. 최종 산출물
- 영수증 합본 PDF (60% 축소 + 표기)
- 기안서 ZIP (기안이 없는 건만)

---

## 입력 파일

| 구분 | 위치 | 설명 |
|------|------|------|
| 영수증 | 입력/영수증/ | PDF, HTML, PNG, JPG (이미지는 OCR 자동 처리) |
| 승인내역 | 입력/승인내역/ | 파일명에 "국내" 또는 "(1)" 포함 시 국내, "해외" 포함 시 해외 |
| 마스터 엑셀 | 기준/2026 AI.xlsx | 계정별 사용자·카드·기안 여부 정의 |
| 기안서 템플릿 | 기준/기안서_템플릿.hwpx | 기안서 양식 |
