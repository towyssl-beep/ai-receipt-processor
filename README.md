# AI 영수증 처리 — 실행 안내 (VSCode + CLI)

매달 영수증·승인내역을 폴더에 넣고 `python run.py` 한 줄로
**60% 표기 PDF + 기안서**를 만듭니다.

## 폴더 구조 (역할별 분리)
```
C:\CLAUDE\                  ← VSCode에서 이 폴더 열기
├─ run.py                   ← 실행 진입점
├─ config.json              ← 경로 설정(한 번만)
├─ 환율.json                ← (선택) 날짜별 환율 직접지정 / 비우면 자동조회
├─ requirements.txt         ← 설치 패키지 목록
├─ *.py                     ← 프로그램 모듈
├─ 기준\                    ← [고정] 거의 안 바뀜
│   ├─ 2026 AI.xlsx          (계정·매핑 마스터)
│   └─ 기안서_템플릿.hwpx    (기안서 한글 양식)
├─ 입력\                    ← [매달 교체]
│   ├─ 영수증\              (그 달 영수증: Receipt·Gmail PDF 등)
│   └─ 승인내역\            (우리카드 승인내역 PDF, 국내는 파일명에 (1))
└─ 출력\<기간>\            ← 결과물 자동 생성
```
**핵심**: 고정(기준) · 매달 데이터(입력) · 결과(출력)를 폴더로 분리 → 매달 입력 두 폴더만 비우면 되고, 마스터·양식은 안 건드립니다.

## 처음 한 번만 (설치)
1. **Python 설치** — python.org, 3.10 이상. 설치 시 “Add Python to PATH” 체크.
2. **VSCode에서 `C:\CLAUDE` 폴더 열기**, 터미널 열기(`Ctrl` + `` ` ``).
3. 가상환경 + 패키지 설치:
   ```
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. (한 번) “Python: Select Interpreter” → `.venv` 선택 → 이후 `python run.py` 만으로 실행.
   - 더 쉽게: `setup.bat` 더블클릭(설치) → 매달 `run.bat` 더블클릭(실행)

## 매달 실행
1. `입력\영수증\` 에 그 달 영수증, `입력\승인내역\` 에 승인내역 PDF를 넣기.
   - 승인내역: 해외 `6571.pdf`·`8043.pdf`, 국내는 파일명에 `(1)` (예 `6571 (1).pdf`)
   - 지난달 것은 비우고 새로. **기준\ 의 엑셀·양식은 그대로 둠.**
2. `python run.py --period 2026-06`  (`--period` 생략 시 이번 달)
3. 결과: `출력\2026-06\` 에 60% 표기 PDF + 기안서 + 점검 리포트.

## config.json
| 키 | 의미 |
|----|------|
| receipts | 영수증 폴더 (기본 `입력/영수증`) |
| approvals | 승인내역 폴더 (기본 `입력/승인내역`) |
| master | 마스터 엑셀 (기본 `기준/2026 AI.xlsx`) |
| template | 기안서 양식 (기본 `기준/기안서_템플릿.hwpx`) |
| out | 출력 상위 폴더 |
| online | 환율 인터넷 자동조회(true 권장) |
| fx | 환율 직접지정 파일 |

## 참고
- **승인내역이 정답지** — 영수증이 안 맞으면 해당 영수증에 ‘미매칭’ 표기 → 회계팀 보완 요청.
- **기안서 금액** = `$ × 실행일 환율` (인터넷 자동조회). 실행 후 화면의 `환율:` 줄에서 출처 확인. 막히면 `환율.json`에 `{"2026-06-11": 1390}` 직접 입력.
- **사용자 (미지정)** = 마스터 엑셀에 그 이메일 추가하면 다음부터 자동.
